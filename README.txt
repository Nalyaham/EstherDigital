ESTHER DIGITAL - HTML, Tailwind CSS & JavaScript

1. Keep all files and folders together.
2. Open index.html in a browser (internet needed: Tailwind loads from its CDN).

index.html, products.html, details.html, contact.html  Pages
tailwind-config.js  Colours, font and shadows (edit the design here)
fonts.css           Newsreader @font-face rules
script.js           Header/footer, mobile menu, contact form, purchase dialog
images/, fonts/     Pictures and font files

Mobile layout = below 768px; desktop = 768px and up.
The CDN build is for development; for production, compile Tailwind with its CLI.
